# Backend Developer Portfolio

A clean, terminal-inspired portfolio website showcasing backend engineering skills, API design, and cloud deployment. 

🔗 **[Live Demo on Render](https://festus-backend-portfolio.onrender.com)**

## 📌 Overview

This project serves as a professional portfolio for a Backend Developer. Unlike traditional static portfolios, this project is built as a **full-stack Node.js application**. It features a custom Express server that serves the static frontend assets while also providing functional REST API endpoints.

## 🚀 Features

- **Express Server:** Serves the static frontend and handles API routing.
- **API Status Endpoint (`/api/status`):** A health check endpoint that returns the server's uptime and status.
- **Contact Form Endpoint (`/api/contact`):** Simulates receiving a contact form submission and logs it to the server console.
- **Responsive UI:** A clean, IDE-inspired dark theme built with vanilla HTML, CSS, and JavaScript.
- **Cloud Deployment:** Configured for seamless deployment on Render.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Tools:** Git, GitHub, Render, Dotenv
- **Dependencies:** `express`, `cors`, `dotenv`

- **Project Structure**
- backend-portfolio/
├── public/
