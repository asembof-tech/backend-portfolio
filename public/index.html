01. About Me

Hello! I'm Festus, a backend engineer based in Port Harcourt, Nigeria. My journey in software engineering started with a curiosity for how data moves across the internet, and it has evolved into a passion for building the invisible infrastructure that powers modern applications.

I enjoy tackling complex architectural challenges, whether it's reducing database query latency, designing event-driven microservices, or implementing secure authentication flows. I believe that a great backend is one that is invisible to the user because it just works—reliably and efficiently.
